# Sunspot

Sunspot is a Python toolkit for comparing daily activity series with
sunspot and geomagnetic observations. It aligns observations by date and
writes exploratory associations, lag and rolling summaries, and plots.

- [Documentation index](docs/README.md)
- [Setup and offline verification](docs/quickstart.md)
- [Input sources and statistical methods](docs/README.md#topical-guides)
- [Scope and interpretation](docs/scope.md)
- [Manuscript](docs/manuscript/README.md)

The [archived author example](report/docxology/README.md) shows the report
format. Its associations describe that saved run. The draft manuscript
replays those artifacts together with synthetic verification fixtures.
