# Abstract {#sec:abstract}

Sunspot is a Python toolkit for aligning daily activity observations with
solar and geomagnetic measurements. It writes associations, lag profiles,
rolling summaries, and diagnostic plots to a reproducible report structure.
This paper documents the package's input boundaries, analysis, and
interpretation using saved data-provider snippets, synthetic test series,
and an archived example for the repository author. The archived example
illustrates how to read the artifacts. Its estimates describe the recorded
window and provide no evidence of a causal effect.
