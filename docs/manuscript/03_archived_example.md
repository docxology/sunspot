# Archived example {#sec:archived-example}

The repository preserves a report for its author under
`report/docxology/`. The saved sunspot-number block reports Pearson
correlation of approximately 0.045 and Spearman correlation of approximately
0.191. These values are rounded from the archived JSON. Their differing
magnitudes illustrate the distinction between a linear and a rank summary.

![Archived sunspot-number association for the repository author. The plotted values come from the original report.](../../output/figures/archived-author-ssn-scatter.png){#fig:archived-author-ssn width=90%}

The figure, rolling table, and lag profile are separate views of that
observation window. The numerical summary and figure describe an archived
example. They neither provide a population estimate nor establish that
solar activity changes commit behavior.
