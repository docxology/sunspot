# `report/`

Archived/example `sunspot` run outputs, kept separate from the default
`output/correlate/` run root. Not generated by CI and not required for
development or tests.

| path | content |
|------|---------|
| `docxology/` | docxology correlation-run exports: `report.json` (per-metric associations/lags, window 2008-01-01 → 2026-04-23) + per-metric folders `ssn/`, `f107/`, `dst/`, `ap/`, `r_ssn/` with PNGs and rolling CSV — see [`docxology/README.md`](docxology/README.md) |

The canonical artifact layout is documented in
[output/README.md](../output/README.md); regenerate runs with
`uv run sunspot correlate …` rather than editing files here. See [AGENTS.md](AGENTS.md).
