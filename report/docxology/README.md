# docxology/

docxology correlation-run report artifacts. The user's anchor run
(`output/correlate/docxology__2019-12-20__2026-04-23/`, per
`output/_logs/docxology.log`) plus a metric sweep over the window
2008-01-01 → 2026-04-23 produced these exports.

| path | content |
|------|---------|
| `report.json` | aggregate statistics for the docxology run (window 2008-01-01 → 2026-04-23, metrics ssn/f107/dst/ap/r_ssn): per-metric Pearson/Spearman/Kendall associations, lag block, and lag min-p fields |
| `ssn/`, `f107/`, `dst/`, `ap/`, `r_ssn/` | per-metric PNGs + rolling CSV (see each folder's README) |

Generated by `sunspot.correlate.run_correlation_report`
([`docs/api/correlate.md`](../../docs/api/correlate.md)); all statistics are
exploratory, not causal. The canonical full run layout lives in
[`output/README.md`](../../output/README.md).

Local-only under `projects/ongoing/DataTools/` — never commit. Parent:
[`../README.md`](../README.md).
